Questions

Before you start

Do I have to use every module?

No. Start with the features that make sense for your business.

Does my whole team have to use it?

No. Many businesses begin with an owner and manager view and add team access when they're ready.

Can we add features later?

Yes. The HQ is designed so new modules and processes can be added over time.

Will it work with systems we already use?

It organizes access to your existing systems and, where practical, connects their information. The exact setup depends on your software and workflow.

Is this an ERP or a CRM?

No. It can include simple CRM-like, project and tracking functions, but the goal is different: one owner-controlled internal operating center.
